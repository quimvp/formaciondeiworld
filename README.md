# Formación de personal de soporte · DeiWorld

Sitio estático de formación práctica para la primera línea de soporte de DeiWorld.

## Contenido

- Protocolo común de atención y escalado.
- Ruta gradual de autonomía.
- 13 cápsulas sobre tickets, tráfico, integraciones, tarifas, Track & Trace, CRM, facturación, contabilidad, cobros, proyectos y aduanas.
- Plantillas reutilizables y seguimiento local del progreso.

## Uso local

Abre `dist/index.html` en el navegador. No requiere instalación ni compilación.

## GitHub Pages

El flujo incluido en `.github/workflows/pages.yml` publica el contenido de `dist/` mediante GitHub Pages.
